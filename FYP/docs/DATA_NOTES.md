# Data notes

The repository contains derived analysis data required to reproduce the reported downstream statistics and figures.

The main completed scan contains 588 successful FST observations:
6 population pairs × (24 X windows + 25 3R windows) × 2 site classes.

The focal X interval is X:13,393,109–17,393,108. Only these four X windows are removed from the background analysis. No 3R window is removed for the focal-X exclusion.

Usable-site counts below 1000 are QC flags rather than automatic exclusion criteria.

Raw MalariaGEN genomic data are not redistributed here.
